5.1 陷阱一：生存偏差 (Survivorship Bias)

问题描述：

如果你只用当前还在交易的股票来回测，你会错过那些已经退市、破产或被收购的股票。这些”失败者”往往是你策略会买入但最终亏损的股票。

举例说明：

假设你在2015年回测，使用的是2023年的标普500成分股列表。但2015年的标普500成分股中，有很多公司后来被踢出了指数（因为表现差），而你的回测完全忽略了它们。

结果： 你的回测收益被人为夸大了。

5.3 陷阱三：滑点与交易成本 (Slippage & Transaction Costs)

问题描述：

回测中假设你能以精确的价格成交，但实际交易中：

  1. 你的订单会影响市场价格（尤其是大单）
  2. 买卖价差（Bid-Ask Spread）会吃掉一部分利润
  3. 券商会收取佣金

5.4 陷阱四：过度拟合 (Overfitting)

问题描述：

通过不断调整参数，让策略在历史数据上表现完美，但这些参数只是”记住”了历史，对未来没有预测能力。

类比理解：

想象你在准备考试。过度拟合就像是你把往年的考题答案全部背下来，但你并没有真正理解知识点。如果今年的考题稍有变化，你就完全不会做了。

过度拟合的信号：

信号 说明
参数过多 策略有超过10个可调参数
参数过于精确 比如”回看期必须是47天”而不是”大约50天”
样本内外差异大 训练集表现远好于测试集
交易次数太少 少于100次交易的回测结果不可靠
收益曲线过于完美 几乎没有回撤的权益曲线很可疑

class RobustnessTest:
“””稳健性测试”””

def __init__(self, config: Config):
    self.config = config

def walk_forward_analysis(
    self, 
    data: dict, 
    train_period: int = 252,  # 1年训练
    test_period: int = 63,    # 3个月测试
    step: int = 21            # 每月滚动一次
) -> list:
    """
    滚动窗口分析 (Walk-Forward Analysis)

    这是检验策略稳健性的黄金标准方法。

    原理：
    1. 用过去1年的数据"训练"（确定参数）
    2. 用接下来3个月的数据"测试"
    3. 滚动窗口，重复上述过程
    4. 只看测试期的表现
    """
    results = []

    # 获取所有交易日
    all_dates = sorted(data[list(data.keys())[0]].index)

    start_idx = train_period

    while start_idx + test_period < len(all_dates):
        # 训练期
        train_start = all_dates[start_idx - train_period]
        train_end = all_dates[start_idx - 1]

        # 测试期
        test_start = all_dates[start_idx]
        test_end = all_dates[min(start_idx + test_period - 1, len(all_dates) - 1)]

        # 在训练期优化参数（可选）
        # optimized_params = self.optimize_params(data, train_start, train_end)

        # 在测试期运行策略
        test_result = self.run_backtest(data, test_start, test_end)

        results.append({
            'train_period': (train_start, train_end),
            'test_period': (test_start, test_end),
            'test_return': test_result['total_return'],
            'test_sharpe': test_result['sharpe_ratio'],
            'test_trades': test_result['total_trades']
        })

        start_idx += step

    return results

def parameter_sensitivity_analysis(
    self, 
    data: dict, 
    param_name: str, 
    param_range: list
) -> pd.DataFrame:
    """
    参数敏感性分析

    检验策略对单个参数变化的敏感程度。
    如果参数稍微变化，策略表现就大幅下降，说明过度拟合。
    """
    results = []

    for param_value in param_range:
        # 修改参数
        setattr(self.config, param_name, param_value)

        # 运行回测
        result = self.run_backtest(data)

        results.append({
            'param_value': param_value,
            'total_return': result['total_return'],
            'sharpe_ratio': result['sharpe_ratio'],
            'max_drawdown': result['max_drawdown'],
            'win_rate': result['win_rate']
        })

    return pd.DataFrame(results)

def monte_carlo_simulation(
self,
closed_trades: list,
num_simulations: int = 1000,
initial_capital: float = 100000
) -> dict:
“””
蒙特卡洛模拟 (Monte Carlo Simulation)

    原理：
    1. 打乱交易顺序，重新计算权益曲线
    2. 重复1000次
    3. 观察不同顺序下的结果分布

    目的：
    - 了解策略的"运气成分"有多大
    - 估计最坏情况下的回撤
    - 计算破产概率
    """
    # 提取每笔交易的收益率
    trade_returns = [t['pnl_pct'] for t in closed_trades]

    simulation_results = []

    for _ in range(num_simulations):
        # 随机打乱交易顺序
        shuffled_returns = np.random.permutation(trade_returns)

        # 计算权益曲线
        equity = initial_capital
        equity_curve = [equity]
        max_equity = equity
        max_drawdown = 0

        for ret in shuffled_returns:
            # 假设每笔交易使用固定比例的资金
            position_size = equity * 0.15  # 15%仓位
            pnl = position_size * ret
            equity += pnl

            equity_curve.append(equity)

            # 更新最大回撤
            max_equity = max(max_equity, equity)
            drawdown = (max_equity - equity) / max_equity
            max_drawdown = max(max_drawdown, drawdown)

        # 计算该模拟的统计数据
        total_return = (equity - initial_capital) / initial_capital

        simulation_results.append({
            'final_equity': equity,
            'total_return': total_return,
            'max_drawdown': max_drawdown,
            'min_equity': min(equity_curve),
            'went_bankrupt': min(equity_curve) <= 0
        })

    # 汇总统计
    results_df = pd.DataFrame(simulation_results)
